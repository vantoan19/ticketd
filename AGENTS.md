# Repository conventions

Keep durable product requirements, domain definitions, and architectural decisions in the repository. Track features, bugs, implementation plans, and progress in GitHub Issues; do not create local ticket or progress documents.

## Agent skills

### Issue tracker

Before creating, reading, or updating work items, read `docs/agents/issue-tracker.md`. Use this repository's GitHub Issues through `gh`.

### Triage labels

Before triaging or assigning readiness labels, read `docs/agents/triage-labels.md` for the canonical vocabulary.

### Domain docs

Before exploring or changing domain behavior, read `docs/agents/domain.md`. This repository uses a single domain context.
